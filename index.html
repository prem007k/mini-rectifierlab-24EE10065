Converter Theory & Mathematical Derivations

Rigorous step-by-step calculus, voltage equations, and switch commutation physics.
1. Resistive (R) Load Derivation

With a purely resistive load, the thyristor conducts from firing angle α until the AC input voltage naturally crosses zero at π (180°). During the negative half-cycle (π to 2π), the thyristor is reverse-biased and blocks conduction.

Vdc = 12π ∫πα Vm sin(ωt) d(ωt)
= Vm2π [ -cos(ωt) ]πα = Vm2π (-cos(π) - (-cos(α)))
= Vm (1 + cos α)2π
For uncontrolled diode rectifier (α = 0°): Vdc = Vm / π ≈ 0.318 Vm. At 230 V RMS (Vm = 325 V), Vdc ≈ 103.45 V.
2. Inductive (R-L) Load & Extinction Angle β

When an inductor is present in series with R and no freewheeling diode is connected, the inductor opposes the collapse of current. The induced voltage vL = L (di/dt) forces the thyristor to remain in conduction past π into the negative half-cycle until stored magnetic energy drops to zero at the extinction angle β (> π):

L didt + R i = Vm sin(ωt)
i(ωt) = VmZ [ sin(ωt - φ) - sin(α - φ) e-(ωt - α) / tan φ ]
where Z = √R2 + (ωL)2,   tan φ = ωLR
Vdc = Vm (cos α - cos β)2π
Notice that because conduction continues into the negative voltage region (π to β), the output voltage vo dips negative, reducing the average DC output voltage. Conduction angle is γ = β - α.
1. Single-Phase Full-Wave Bridge (Resistive Load)

The bridge rectifier produces 2 identical output pulses per supply cycle (period T0 = π rad = 10 ms at 50 Hz). For R load, current extinguishes at π:

Vdc = 1π ∫πα Vm sin(ωt) d(ωt)
= Vm (1 + cos α)π
At α = 0°, Vdc = 2Vm / π ≈ 0.6366 Vm = 206.90 V (for Vm = 325 V). Exactly double the half-wave output!
2. Continuous Conduction Mode (Heavy Inductive Load)

When load inductance L is sufficiently large, the load current never falls to zero (Continuous Conduction Mode, CCM). Thyristors T1+T2 conduct from α up to π + α, at which point the incoming pair T3+T4 is triggered and commutates the current:

Vdc = 1π ∫π + αα Vm sin(ωt) d(ωt)
= Vmπ [ -cos(ωt) ]π + αα = Vmπ ( -cos(π + α) + cos(α) )
= 2 Vm cos απ
Crucial Physical Property: For α > 90°, Vdc becomes NEGATIVE! If connected to a DC source or motor back-EMF, power flows from the DC side back into the AC grid (Line-Commutated Inverter Mode).
Three-Phase Half-Wave (3-Pulse Midpoint Star Converter)

The supply consists of 3 balanced phases 120° apart. The natural commutation crossover occurs at ωt = 30° (π/6) where phase A becomes more positive than phase C. Each thyristor conducts for 120° (2π/3 rad):

For continuous conduction (α ≤ 30°):
Vdc = 32π ∫5π/6 + απ/6 + α Vm sin(ωt) d(ωt)
= 3√3 Vm cos α2π ≈ 0.827 Vm cos α
For resistive load discontinuous mode (α > 30°):
Vdc = 32π ∫ππ/6 + α Vm sin(ωt) d(ωt) = 3 Vm [ 1 + cos(α + 30°) ]2π
Extinction angle for R load: Output becomes 0 V when α ≥ 150°. Ripple fundamental frequency is 3 × 50 Hz = 150 Hz.
Three-Phase Full-Wave Bridge (6-Pulse Converter)

The 6-pulse bridge rectifier operates across the line-to-line supply voltages. Peak line voltage is Vm,LL = √3 Vm ≈ 1.732 × 325 V = 563 V. Natural commutation reference is at 60° (π/3):

For continuous conduction (α ≤ 60°):
Vdc = 62π ∫2π/3 + απ/3 + α √3 Vm sin(ωt) d(ωt)
= 3√3 Vm cos απ = 3 Vm,LL cos απ ≈ 1.654 Vm cos α
For resistive load discontinuous mode (60° < α ≤ 120°):
Vdc = 3√3 Vmπ [ 1 + cos(α + 60°) ]
Fundamental Commutation Law & Branch Protection:
In a 3-phase full bridge, the 6 switches are partitioned into 3 phase legs: Phase A (T1 top, T4 bot), Phase B (T3 top, T6 bot), and Phase C (T5 top, T2 bot).
Two thyristors of the SAME phase leg (e.g. T1+T4, T3+T6, or T5+T2) must NEVER conduct simultaneously! That would create a catastrophic phase-to-phase shoot-through short circuit across the supply lines.
Instead, exactly ONE upper switch and ONE lower switch from different phase legs conduct at any time, transferring current smoothly through the standard 6 intervals: (T1+T6) → (T1+T2) → (T3+T2) → (T3+T4) → (T5+T4) → (T5+T6) → (T1+T6).
